# Enamad Crawler & Trustseal Extractor (Golang)

این ابزار با زبان **گولنگ (Go)** توسعه داده شده است تا اطلاعات دامنه‌ها و شناسنامه کسب‌وکارهای ثبت شده در [سامانه نماد اعتماد الکترونیکی (اینماد)](https://enamad.ir/DomainListForMIMT) و صفحه شناسنامه (`trustseal.enamad.ir`) را با **حذف هوشمند موارد تکراری** و **ثبت تاریخ شمسی و روز استخراج** ذخیره کند.

---

## 🚀 ویژگی‌های کلیدی

1. **ثبت زمان، تاریخ شمسی و روز هفته استخراج:**
   - **`ExtractionDate`**: تاریخ شمسی استخراج (مثال: `1405/08/18`)
   - **`ExtractionDay`**: روز هفته به فارسی (مثال: `دوشنبه`)
   - **`ExtractionTime`**: ساعت دقیق استخراج (مثال: `10:42:20`)
   - **`ExtractedAt`**: برچسب زمانی استاندارد ISO 8601 (مثال: `2026-11-09T10:42:20+03:30`)

2. **فیلتر و حذف خودکار داده‌های تکراری (Deduplication):**
   - **یکتاسازی دامنه:** نرمال‌سازی خودکار دامنه‌ها جهت جلوگیری از ثبت دامنه تکراری.
   - **یکتاسازی شماره تماس / موبایل:** چنانچه شماره تماسی قبلاً برای کسب‌وکار دیگری ثبت شده باشد، به صورت خودکار شناسایی و رد می‌شود.
   - **حافظه پایدار بین دفعات اجرا (`-dedup-existing`):** با اجرای مجدد، رکوردهای قبلی بارگذاری می‌شوند تا هیچ رکورد یا شماره تکراری جدیدی ذخیره نشود.

3. **استخراج مستقیم از لینک شناسنامه نماد (بدون نیاز به حل کپچا):**
   - استخراج مستقیم با `-url` یا به صورت دسته‌ای از فایل با `-file`
   - استخراج شماره همراه/ثابت، صاحب امتیاز، ایمیل، آدرس و ساعت پاسخگویی

4. **کراول و استخراج دسته‌ای از لیست کل دامنه‌ها (`DomainListForMIMT`):**
   - دانلود کپچا و دریافت ورودی از کاربر برای ورود به سیستم جستجو (Human-in-the-Loop)
   - استخراج لینک شناسنامه هر کسب‌وکار و باز کردن موازی آن‌ها با ورکر‌های هم‌روند (`Goroutines`)
   - ذخیره‌سازی داده‌ها در دو قالب استاندارد **CSV** و **JSON**

## نحوه اجرا

### ۱. استخراج یک لینک تکی:
```bash
./enamad-crawler -url "https://trustseal.enamad.ir/?id=10480393&code=6glScXMuHtDxiVuFwqSKASeAKvZgeyRt"
```

خروجی نمونه در ترمینال:
```text
اطلاعات استخراج شده از اینماد:
• نام صاحب امتیاز: قاسم عزیزی
• شماره تماس:      09120372746 (موبایل)
• ایمیل:            info[at]romnemishe.ir
• ساعات پاسخگویی:  09:00 الی 18:00
• آدرس پستی:        استان : تهران - شهرستان : تهران - بخش : مرکزی - شهر : تهران - محله : اسکندری - خیابان بوستان سعدی - بزرگراه نواب صفوی - پلاک : 531.0 - طبقه : 3 - واحد : 135
• روز و تاریخ:     دوشنبه (1405/08/18) - ساعت 10:42:20
```

### ۲. کراول کامل از لیست اینماد با حذف تکراری‌ها:
```bash
./enamad-crawler -pages 3 -concurrency 10
```

### ۳. استخراج دسته‌ای از روی فایل متنی (بدون نیاز به کپچا):
```bash
./enamad-crawler -file urls.txt -concurrency 10 -out clean_results
```

## ستون‌های خروجی CSV

| نام ستون | توضیحات |
|---|---|
| `Domain` | نام دامنه کسب‌وکار |
| `BusinessName` | نام فارسی ثبت‌شده در اینماد |
| `Province` / `City` | استان و شهر فعالیت |
| `Rating` | تعداد ستاره‌های اینماد |
| `TrustsealURL` | آدرس صفحه شناسنامه اینماد |
| `OwnerName` | نام و نام خانوادگی صاحب امتیاز |
| `Phone` | شماره تلفن استخراج‌شده |
| `IsMobile` | آیا شماره از نوع موبایل است (`true` / `false`) |
| `Address` | آدرس پستی ثبت‌شده در نماد |
| `Email` | ایمیل رسمی کسب‌وکار |
| `ResponseHours` | ساعات پاسخگویی |
| `ExtractionDate` | **تاریخ شمسی استخراج (مثال: `1405/08/18`)** |
| `ExtractionDay` | **روز هفته به فارسی (مثال: `دوشنبه`)** |
| `ExtractionTime` | **ساعت دقیق استخراج (مثال: `10:42:20`)** |
| `ExtractedAt` | **تایم‌استمپ کامل ISO 8601** |
